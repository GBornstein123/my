# Faceless X Page — Build System

A complete, executable build-out of the "faceless page" model, specified for one niche:
**independent contractor / 1099 self-employment taxes**, selling a $47 guide on Gumroad.

Everything here is an artifact you can act on, not a summary of the idea.

## Before you ship anything

Two gates, both non-optional:

1. **Verify every tax figure.** `GUIDE.md` and `CONTENT-LIBRARY.md` each end with a
   `VERIFY BEFORE PUBLISH` / `VERIFY BEFORE POSTING` checklist. Rates, thresholds, deadlines,
   and the standard mileage rate change annually. Re-check each against the cited IRS source
   before publishing, and again every January. A wrong number in a paid tax guide is not a typo —
   it is a real cost to a real buyer.
2. **Keep the disclaimer, and mean it.** This is educational information, not tax advice. The
   page has no CPA or EA behind it and must never imply otherwise. The VA playbook's hard boundary
   on "never give tax advice" exists for the same reason.

## What this system does not claim

The source thread asserts specific figures — a 34% conversion lift at 25 reviews, an 11%→31%
review rate with follow-up, $5,000/month per page, $300k/month at nine pages. These come from one
anonymous account with no published data behind them. The files here reproduce the *mechanics*
(reviews compound, follow-up raises response rate, the model is horizontally repeatable) without
adopting the numbers as fact. `REVIEW-ENGINE.md` and `SCALING-AND-TIMELINE.md` label them as
unverified and give you a way to measure your own instead.

The honest version: this is a real business model with a real failure rate. Most pages built this
way earn very little. The distribution is not the average. `SCALING-AND-TIMELINE.md` covers what
actually goes wrong.

## Swapping the niche

If you'd rather run a different niche, `00-SPINE.md` is the only file that needs rewriting first —
then regenerate 01 through 04. The systems layer (05) is niche-independent and carries over to
every page you build after this one. `PAGE-SETUP.md` includes a table of what's reusable.
