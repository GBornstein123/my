MiniFlow

Hold a key, speak, release — polished text appears wherever your cursor is.

1 · The hotkey

Hold Right Ctrl (changeable in the tray menu), speak, release. Works in any app: Slack, Gmail, VS Code, anywhere you can type.

2 · Microphone access

Windows will ask for microphone permission on first use. If dictation stays silent, check Settings → Privacy & security → Microphone and allow desktop apps.

3 · API keys (cloud mode)

Create a file named .env in the MiniFlow folder:

  • GROQ_API_KEY=… — transcription (or OPENAI_API_KEY)
  • ANTHROPIC_API_KEY=… — optional, enables Claude cleanup; without it a local rules cleaner is used

4 · Local mode (no cloud at all)

Run scripts/setup-local-mode.ps1 once to download whisper.cpp, then flip the tray toggle to Local. Audio and text never leave this PC — the cleanup pass automatically switches to the offline rules engine.

That's the whole list. No accounts, no analytics, no sync. Audio files are deleted right after transcription. Your last 10 dictations are kept in a local file for the tray history (your recovery net if a paste ever fails) — nothing else is stored.

Close this window to start. Reopen it any time from the tray → Setup guide.
