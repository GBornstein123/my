Substack & paid newsletters: connect Gmail above, or save the email (Gmail desktop: ⋮ → “Download message”) and import the .eml. The reader strips the buttons and footer and keeps the article.

Books: DRM‑free EPUBs import fully, chapter by chapter. Kindle purchases (.azw/.kfx) are locked by Amazon’s DRM and can’t be opened outside Kindle apps.

Works for public pages — Substack publications list their recent posts. Paid/paywalled posts come in through Gmail or .eml import instead.

One-time setup — the app talks to Gmail directly from your browser (read-only; nothing leaves your device), but Google requires it to have its own credential:

1. Go to console.cloud.google.com → create a project
2. APIs & Services → Library → enable the Gmail API and the Google Drive API
3. OAuth consent screen → External → add your own Gmail address as a test user
4. Credentials → Create credentials → OAuth client ID → Web application → under Authorized JavaScript origins add the URL you open this app from (e.g. your GitHub Pages origin)
5. Paste the client ID below
